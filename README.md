# Running Training Tracker 🏅

A personal training companion to log runs, mobility work, strength exercises, and plan for races.

## Features

- **Training Log** — log runs with date, distance, duration, pace, and notes
- **Mobility** — track stretching and foam rolling sessions
- **Strength** — log exercises with sets, reps, and weight
- **Race Planner** — add a goal race and get a week-by-week training plan

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Tech Stack

- [React](https://react.dev) + [Vite](https://vite.dev)
- [Tailwind CSS](https://tailwindcss.com)
- localStorage for data persistence
